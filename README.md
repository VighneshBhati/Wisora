# Wisora

> **Talk to real experience.**

Wisora is India's expert guidance platform. Book 1-on-1 sessions with verified professionals — career coaches, doctors, lawyers, founders, artists, and more. No fluff. Just real conversations with people who've actually been there.

---

## What is Wisora?

Most platforms sell you courses. Wisora gives you access to people.

Whether you're a student figuring out your career, a professional making a pivot, or an institution looking to upskill your team — Wisora connects you directly with verified experts for live, on-demand guidance sessions.

---

## User Modes

| Mode | Who it's for |
|------|-------------|
| **Personal** | Students & individuals seeking 1-on-1 expert sessions |
| **Institutional** | Colleges & enterprises managing team-wide expert access |
| **Expert** | Verified professionals offering their time & knowledge |

One login. All three modes.

---

## Core Features

- 🎯 **Expert Discovery** — Browse verified experts by domain, rating, and availability
- 📅 **Session Booking** — Book 30/60 min slots directly with experts
- 💬 **AI Assistant** — Context-aware chatbot to help navigate the platform
- 🏛️ **Institutional Dashboard** — Manage users, events, and expert bookings at scale
- 💳 **Wallet & Subscriptions** — Credits-based system with personal & institutional plans
- 📊 **Expert Earnings** — Transparent payout tracking for experts
- 🔐 **Google OAuth** — One-click sign in

---

## Tech Stack

- **Frontend** — React + TypeScript + Vite
- **Styling** — Tailwind CSS + styled-components
- **Backend** — Supabase (Auth, Database, Storage, Edge Functions)
- **State** — Redux Toolkit
- **AI** — OpenRouter API
- **Deployment** — Vercel

---

## Getting Started

```bash
# Install dependencies
npm install

# Set up environment variables
cp .env.example .env
# Fill in your Supabase and OpenRouter keys

# Run locally
npm run dev
```

---

## Environment Variables

```env
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
VITE_OPENROUTER_API_KEY=your_openrouter_key
```
